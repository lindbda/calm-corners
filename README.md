# Calm Corners

Free, interactive calm-down spaces for the classroom. Students can touch, listen to, and breathe along with each scene.

**Open it:** https://lindbda.github.io/calm-corners/

| Scene | What it is |
| --- | --- |
| [Still Water](https://lindbda.github.io/calm-corners/still-water.html) | A living koi pond. Touch the water for ripples and soft notes. |
| [Cozy Cat Room](https://lindbda.github.io/calm-corners/cozy-cat-room.html) | A lamplit room full of cats to pet, with yarn to dangle. |

Every scene includes a breathing guide (Balloon, Square, 4-7-8), a calm timer, background music, and rain.

- Works on smartboards, Chromebooks, tablets, and phones
- No accounts, ads, or tracking, and no student data collected
- Each scene is a single HTML file with no build step

Free to use and share with other teachers.
